# VEILLEMM — Asset Intelligence

Art direction for the **Frequency Atelier** concept.

## Strategy decision

This build ships with a **fully self-authored, generative visual system** instead of
downloaded photography. Rationale:

1. **Originality** — the brief demands an experience that never feels like a template or
   stock. Every visual (hero signal field, project canvases, brand mark) is generated by
   code we wrote, so the identity is 100% unique to VEILLEMM.
2. **Licensing zero-risk** — no watermarks, no attribution headaches, no broken hotlinks.
3. **Performance** — zero image weight. The entire experience ships as a few kilobytes of
   HTML/CSS/JS, which is the premium baseline.
4. **Cohesion** — every frame obeys the same tokens (ink / bone / signal amber), which stock
   photography can never guarantee.

The visual assets that exist are **generative by design**: canvas-driven motion systems
(see `js/canvas.js`) and vector brand graphics (`logo.svg`, `favicon.svg`, `og-cover.svg`).

## Optional premium photography swap

If a future iteration wants real imagery, the recommended sources (all royalty-free /
commercial-use) are:

- **Unsplash** — `https://unsplash.com/s/photos/architecture-dark`, `.../abstract-dark`,
  `.../workspace-dark` (filter: "Editorial")
- **Pexels** — `https://www.pexels.com/search/dark%20technology/`
- **Pixabay** — `https://pixabay.com/images/search/dark%20abstract/`

Rules if swapping:
- Never hotlink watermarked previews; download full files into `assets/images/`.
- Use descriptive filenames, e.g. `assets/images/veillemm-atelier-desk.jpg`.
- Keep the palette discipline: dark, warm-neutral, low-saturation frames only, so the
  signal-amber accent keeps its authority.
- Run every asset through `squoosh.app` (WebP/AVIF, ~60-80 quality) before committing.

## Favicon & OG

- `favicon.svg` is referenced from `<head>` and doubles as the theme-color hint.
- `og-cover.svg` renders identically at 1200×630. For maximum crawler compatibility,
  export a PNG version with `rsvg-convert -w 1200 -h 630 og-cover.svg -o og-cover.png`
  and update the `og:image` meta tag to point at the PNG.
