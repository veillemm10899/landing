# SEE — The Art of the Golden Hour

A cinematic travel showcase by **VEILLEMM** (Cyrus Vergara) celebrating the world's
most beautiful sunset views, beaches, and paradise escapes.

## Run locally

Any static server works:

```bash
# from this folder
python3 -m http.server 8080
# then open http://localhost:8080
```

## Structure

```
See/
├── index.html        # Single-page cinematic experience
├── styles.css        # Design system (dark + gold, Fraunces/Outfit)
├── main.js           # Interactions: preloader, parallax, lightbox, cursor…
├── assets/
│   └── images/       # 20 curated golden-hour photographs (Unsplash CDN)
└── README.md
```

## Feature list

- Cinematic preloader with golden progress bar
- Parallax hero + chapter media layers
- Editorial destination mosaic (8 horizons, tap for full-screen lightbox)
- Drag & arrow-driven horizontal beach gallery
- Scroll-triggered reveals, count-up stats, magnetic buttons
- Custom cursor on fine-pointer devices
- Full accessibility: semantic HTML, alt text, keyboard-lightbox, reduced-motion support
- Fully responsive from mobile to desktop
